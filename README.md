# FINCORE Platform

Enterprise-grade financial platform built with Java and Spring Boot.

## Architecture

FINCORE is a distributed financial platform based on:

- Java
- Spring Boot
- Spring Security
- Spring Cloud Gateway
- PostgreSQL
- Kafka
- Spring Cloud Stream
- Spring Batch
- Docker
- Kubernetes
- Prometheus
- Grafana
- ELK
- JUnit 5
- Mockito
- Testcontainers

## Microservices

- edge-service
- identity-service
- wealth-service
- ledger-service
- execution-service
- quant-service
- intelligence-service

## Architecture Principles

- Domain-Driven Design
- Hexagonal Architecture
- Clean Architecture principles
- Event-Driven Architecture
- CQRS
- Transactional Outbox
- Database per Service
- Eventual Consistency
- Strong consistency for financial operations

## Project Goals

The objective is to build a production-oriented financial platform demonstrating:

- advanced Java
- advanced Spring Boot
- distributed systems
- financial domain modeling
- concurrency
- event-driven architecture
- advanced PostgreSQL
- security
- observability
- testing
- CI/CD
- Kubernetes
